Useful List of Commands

(Courtesy of sinclair — cleaned up for clarity)

Service Management

systemctl status service
Check the status of a service.
systemctl start service
Start a service.
systemctl stop service
Stop a service.
systemctl restart service
Restart a service.
systemctl enable service
Enable a service to start on boot.
systemctl disable service
Disable a service from starting on boot.
sudo apt install bum
On-Boot Service Manager GUI (Boot-Up Manager).
systemctl list-units --type=service --state=running
List all running services.
systemctl list-units --type=service --state=active
List all active services.

Packages (updates and such)

sudo apt-get update or sudo apt update
Update current package list and prepare for download.
sudo apt-get upgrade or sudo apt upgrade
Upgrade (download and install) currently installed packages.
sudo apt-get install package
Install a specific new package.
sudo apt-get remove package / sudo apt purge package
Remove a package (purge also removes config files).

User Management

adduser username / sudo adduser username
Create a new user (interactive, creates home directory).
deluser username / sudo deluser --remove-home username
Delete a user (optionally remove home directory).
passwd username / sudo passwd username
Change a user’s password.
usermod -a -G group username
Add user to a group (append).
sudo gpasswd -d username groupname
Remove a user from a group.

Other common commands can be discovered online. Linux’s open-source nature means good documentation is almost always available.
